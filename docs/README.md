# docs の歩き方

このフォルダには22本のドキュメントがあります。**どこから読めばいいか**と、
本文に断りなく出てくる **`P3` `S6` `R2` のような記号の意味**をここにまとめます。

---

## 1. どれから読むか

| 知りたいこと | 見るもの |
|---|---|
| **結局どうなったのか**（数字だけ） | `progress-log.md` 第2部 — 全測定結果を主題別に。**まずここ** |
| いつ・何をして・何がわかったか | `progress-log.md` 第1部 — 時系列。索引を兼ねる |
| なぜそう作ったのか（要件・設計判断） | `PRD.md` — 728行。長いので目次から必要な節へ |
| 使い方（インストールとコード例） | リポジトリ直下の `README.md` |
| 個別の測定の手順と生の数字 | 下の「日付つきドキュメント」 |

はじめて読む人は **`progress-log.md` 第2部 → 第1部 → `PRD.md`** の順が最短です。
`progress-log.md` の冒頭には MAE・p値・fold といった用語の説明もついています。

---

## 2. 記号の読み方

日付つきドキュメントのタイトルには `（P2）` `S4 を満たした` のような記号が出てきます。
これは3種類あり、**すべて `PRD.md` で先に決めたもの**です。

### P — 検証フェーズ（何をやるかの計画）

「何と比べて勝てば価値があると言えるか」を、作る前に固定した作業単位。定義は `PRD.md` §8。

| | 内容 | 状態 |
|---|---|---|
| P0 | ベースライン測定（比較の土台を作る） | 完了 |
| P0.5 | 先行事例のベースラインを埋める（TabPFN = R6 / CAAFE = R2） | 完了 |
| P1 | 機能A を実装し、複数車種で測る | 完了 |
| P2 | 未知の車種名だけで測り直す | 完了 |
| P3 | 機能B を実装し、証拠つきで測る | 完了 |
| P3.5 | 機能A の LLM フォールバック（設計書05）を実測 | 完了 |
| P4 | 閾値を振って精度・費用・レイテンシの曲線を出す | 完了 |
| P4.5 | 信頼度ルーティングをライブラリにする（`AdaptivePredictor`） | 完了 |
| P5 | 画像モダリティを追加 | **実施不能**（画像URLが全滅） |

P0.5 を P1 より先に置いたのは、**LLM を使わない到達点（TabPFN）を知らないまま
機能A を作ると、改善したかどうかを判定できない**ためです。

### S — 受け入れ基準（合格ラインの定義）

作る前に決めた合格ライン。定義は `PRD.md` §4.2、達成状況の一覧は `progress-log.md` 第2部 §2。

| | 基準 | 判定 |
|---|---|---|
| S1 | 機能A が比較線を有意に下回る | 同着 |
| S2 | 機能A が未知車種名で文字TF-IDF に勝つ | **未達** |
| S3 | 機能A が人手ルールに負けない | 達成 |
| S4 | 機能A が CAAFE に勝つ | 達成 |
| S5 | TabPFN に勝つ | 達成 |
| S6 | 機能B が最良の単体モデルを有意に下回る | 達成 |
| S7 | コストを提示できる | 達成 |
| S8 | 来歴を辿れる | 達成 |

### R — 先行事例（比較対象の論文）

`related-work.md` に整理した14本のうち、要件に影響する8本に番号を振ったもの。
対比表は `PRD.md` §3。

| | 論文 | 本プロジェクトとの関係 |
|---|---|---|
| R1 | Industrial Car Retrofit Prediction | 最も条件が近い。結論が**一致** |
| R2 | CAAFE（LLM に特徴量生成コードを書かせる） | 機能A と**設計が対立**する → S4 で直接比較 |
| R3 | Why LLMs Fail at Tabular Prediction | LLM 単体の限界の根拠 |
| R4 | TabLLM（行を自然文にして LLM に入力） | 超少数サンプル域の話なので**射程外** |
| R5 | Quantile Regression with LLMs for Price Prediction | 設計が最も近いが、前提（テキストが主情報）が食い違う |
| R6 | TabPFN | LLM を使わない側の到達点 → S5 で直接比較 |
| R7 | ProbSAINT（中古車価格・予測分布） | 指標設計の宿題（点推定だけでよいか） |
| R8 | AutoML-Agent / SELA ほか | 方式②に対応。**意図的にスコープ外** |
