# Craigslist の画像URLは全滅している（P5 の前提が崩れた）

**日付**: 2026-08-29
**結論**: `vehicles.csv` の `image_url` は **100件中100件が HTTP 404**。
投稿ページ（`url` 列）も同様に 404 で「削除済み」を返す。
**PRD §8 の P5（画像モダリティ）を Craigslist データで実施することはできない。**

## なぜ確認したか

PRD では P5 として「Craigslist の `image_url`（9割充足）を使えば画像モダリティを検証可能」と
書いていた。この作業は見積もりで半日〜1日以上かかる最大の項目だったため、
着手する前に **100件だけ実際に叩いて生存率を測った**（投資15分）。

## やったこと

`scripts/check_image_urls.py` を作成。クレンジング済みの 200,374 行に対応する
`image_url` を 100 件サンプリングし（seed=42）、並列8で実際に GET する。

craigslist は削除済み投稿でも HTTP 200 でプレースホルダ画像を返すことがあるため、
ステータスコードだけで判定せず、本文のハッシュを取って同一画像の多発も検出できるようにした。

```bash
.venv/bin/python scripts/check_image_urls.py -n 100
```

## 結果

| 項目 | 結果 |
|---|---|
| HTTP 200 かつ本文あり | **0 / 100（0.0%）** |
| HTTP エラー | 100 件、すべて **404** |
| 通信失敗（タイムアウト等） | 0 件 |
| 所要 | 100件を並列8で 8.0 秒（80 ms/件） |

### ネットワーク側の問題ではないことの確認

- `https://www.craigslist.org/about/sites` は **200**（89,793 bytes）を返す。接続は生きている
- タイムアウトや DNS 失敗は 0 件。サーバーが明示的に 404 を返している

### 画像だけでなく投稿ごと消えている

投稿ページ本体（`url` 列）を6件サンプリングして叩いたところ、
**6件すべてが 404 で、本文に「削除済み」を示す文言を含んでいた**。

```
投稿ページ 404 削除済み (2021-04) https://montgomery.craigslist.org/ctd/d/montgomery-2018-audi
投稿ページ 404 削除済み (2021-05) https://phoenix.craigslist.org/cph/ctd/d/fontana-2016-ford-s
（他4件も同様）
```

### 一部ではなく全体が死んでいると言い切れる理由

このデータの `posting_date` は **2021-04-04 〜 2021-05-05 の約1ヶ月間に全 426,880 件が収まっている**。
新旧が混在していないので、「古い投稿だけ消えている」という状況ではない。
同じ時期の投稿を無作為に100件引いて全滅した以上、全体が失効していると判断してよい。
craigslist の投稿は掲載期間（30〜45日）を過ぎると本文も画像も削除される仕様で、
収集から5年が経っているため当然の帰結である。

## PRD への影響

以下の記述はもはや成立しない。訂正が必要。

- **§2.3 未着手・ブロッカー** —「Craigslist の `image_url`（9割充足）を使えば検証可能」
  → 充足しているのは CSV 上の文字列であって、指し先の画像は存在しない
- **§8 検証計画 P5** —「画像モダリティ（Craigslist の `image_url`）を追加」
  → このデータでは実施不能

### 取りうる選択肢

1. **P5 を落とす。** インターン期間（〜9/18）を考えると、機能A・機能B に集中する方が期待値が高い。
   仕様書の `Feature(source="image", ...)` は API として設計だけ残し、実測は行わない
2. **画像つきの別データを探す。** ただし「画像 × 価格ラベル × 複数車種」が揃う公開データは限られる。
   探索コスト自体が読めない
3. **カーセンサーで画像を再取得する。** シエンタのデータは自分たちで集めたもので、
   `画像URL` 列は lazy-load のプレースホルダしか取れていない（既知）。
   ブラウザ自動化を足せば取得可能だが、掲載中の車は2026年3月から入れ替わっているため、
   価格と画像の対応を新規に取り直すことになる。単一車種なので §2.2(b) の
   「単一車種では差が出ない」問題も再発する

**推奨は 1。** 画像は今回のデータでは検証できないという事実自体が報告に値する結果であり、
限られた期間を、値が出ることが実測で分かっている機能A・機能B に充てる方がよい。
