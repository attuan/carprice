Capability A — feature engineering

Any column can become a feature.

Declare the source column, the output type, and the values you want. unfold handles embedding, retrieval, classification, and escalation — and caches everything so you only pay for a row once.

features.py
df["sentiment"] = Feature(
    source="customer_comment",
    type="category",
    values=["positive", "neutral", "negative"],
).fit_transform(df)

df["luxury_score"] = Feature(
    source=["image", "description"],
    type="float", range=(0, 1),
).fit_transform(df)

# binary · category · int · float · ordinal
# multilabel · embedding

What runs per row

01 Ground truth
200 labeled examples you already have
02 Multimodal embedding
cached · one vector per record
03 Nearest labeled examples
similarity + label agreement → confidence
04 Confident? Return the label.
no LLM call · ~18 ms · $0.0000
05 Uncertain? Escalate to the LLM.
the answer is written back as a new candidate label

Learn from ground truth

Your labels are the model.

Every labeled record becomes a reference point. A new record is embedded once, matched against the ones you already trust, and answered with the labels of its neighbours — no prompt, no tokens, no round trip.

routing.py
predictor = AdaptivePredictor(
    fast=semantic_model,
    fallback=llm_predictor,
    threshold=0.90,

Everything the fallback answers is queued as a labeling candidate. Accept it and it joins the ground truth, so the fast path covers more of your data next run — the same active-learning loop you would otherwise build by hand.

Capability B — LLM Predict

Give your LLM evidence, not just a prompt.

Familiar API

If you know scikit-learn, you already know this.

The four methods you expect, plus three you always wished you had.

the part you already know
feature.fit(X, y)
feature.transform(X)

model.fit(X, y)
model.predict(X)
model.predict_proba(X)
the part that is new
model.explain(X)      # evidence behind each call
model.confidence(X)   # per-row, before you commit
model.examples(X)     # records it reasoned from
model.cost(X)         # estimate before you run
Everything is swappable

Bring your models. Keep your pipeline.

Providers are configuration, not architecture. Swap an embedding model or move the fallback on-premises without touching a line of feature code.
